# Fiche descriptive du corpus — SI-04, version 0.1 (5 octobre 2026)

Gabarit inspiré des *datasheets for datasets* (Gebru et al., 2021) ; politique d'admission : P1.2, section 3.

- **Motivation.** Fournir, en contexte de consigne, des exemples de ton, de versification ou de contrainte ; jamais
  d'entraînement. Version 0.1 : deux extraits d'essai pour vérifier la chaîne de provenance.
- **Composition.** 2 extraits, 1 œuvre, 1 auteur (Molière, *Amphitryon*, 1668), français classique en vers ;
  0 autrice, 0 voix minoritaire : **déséquilibre à corriger** avant le premier atelier (article A4).
- **Collecte.** Project Gutenberg, livre n° 57270 (éd. Philarète Chasles, Calmann Lévy, 1889), consulté le
  5 oct. 2026 ; catégorie A (domaine public canadien) ; transcription à collationner avec la source.
- **Usages.** Extraits fournis dans la consigne seulement ; la consigne système interdit d'en recopier un vers.
  Usages exclus : entraînement, diffusion intégrale.
- **Maintenance.** Toute entrée est d'abord inscrite au registre `P1-2_Registre_provenance_v1.0.xlsx`, puis dans
  `corpus/corpus.yaml` ; retrait sur demande pour la catégorie E ; revue trimestrielle (politique G.5).
